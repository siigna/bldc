## Why the mark still appears in this tree

Source comments, documentation and protocol identifiers refer to VESC® Tool and
to the upstream firmware where that is a true factual statement — the program a
script is uploaded with, the tool that writes the configuration, the packet ids
this firmware answers. Renaming those references would make the statements
false. Mr. Vedder's trademark policy does not restrict such fair use, and asks
that the owner be acknowledged with a notice; this file is that notice.

Where the name identified *this* software rather than his — the licence
headers, the boot splash, console banners — it has been changed to ESCargot.

## Correct and incorrect usage

Per the policy, compatibility is stated like this:

> ESCargot firmware, compatible with VESC® Software

and **not** as `ESCargot VESC®`, `VESC® ESCargot`, or any phrasing that uses
the mark as part of this product's name, implies endorsement, or presents this
software as a VESC® product.

Questions about the mark go to trademarks@vedder.se, not here.
